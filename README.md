# Studying unique CpG methylation patterns in BRCA pathogenesis

Project conducted by Irena Dikic, Antonia Eisenhofer, Kathrin Kreischer and Marie Sanders

Supervisor: Dr. Michael Scherer, Tutor: Stefanie Mantz

## Abstract
Breast cancer (BRCA) remains a leading cause of mortality among women worldwide, with early detection being critical for improving survival rates. Epigenetic mechanisms, particularly DNA methylation changes at CpG sites, play a crucial role in BRCA pathogenesis. This project investigates unique CpG methylation patterns associated with BRCA using data from the Can- cer Genome Atlas generated by Illumina Infinium Human Methylation 450 Bead Chip array. Differential methylation analysis (DMA) revealed significant differences in CpG sites between BRCA and normal tissues, explored using Principal Component Analysis, Uniform Manifold Approximation and Projection, correlation analysis and hierarchical clustering. Additionally, the most significant genes were identified via DMA and linked to critical pathways implicated in tumorigenesis and metastasis using hallmark gene set enrichment analysis. These pathways include epithelial-mesenchymal transition, myogenesis, apical junction, the KRAS cascade, inflammatory response, IL-2/STAT5 and IL-6/STAT3 signalling. Most importantly, the no- table dysregulation of estrogen response pathways highlight their crucial relevance in BRCA pathogenesis. These findings emphasize the pivotal role of epigenetic mechanisms, particularly methylation patterns, in refining diagnostic strategies and potentially advancing personalized treatment approaches for BRCA.

This project is divided into two parts. You will find three folders: *Data Exploration*, *Data Analysis* and *Data preparation and organisation*. All contain Rmd files with code, whose filenames should be self-explanatory regarding their content. Additionally, there are folders containing the plots and tables generated within the Rmd files.
